# DOG Монитор — памятка для Claude (публичный репозиторий сайта)

Сайт https://dog-monitor.github.io/ (старое имя репозитория `Allexst63/dog-monitor` перенаправляет). Владелец — Алексей,
пишет по-русски; сайт на английском, для людей без опыта в крипте: простые слова, без советов и прогнозов.

- Здесь только то, что отдаёт сайт: сжатая страница `index.html`, данные `data/*.json`, оформление, и задачи Actions,
  которые запускают закрытую часть. Репозиторий и логи Actions видны всем.
- Весь код — в приватном `dog-monitor/engine`: исходник страницы, сбор данных, индекс DOG, сборка, автопроверка. Для любой
  правки подключить оба репозитория и читать `CLAUDE.md` в engine. `index.html` здесь руками не править.
- Ничего из engine сюда не копировать — ни код, ни его куски в коммитах и логах.
- Утренняя задача берёт готовое сообщение из `data/message.md`; запись о запасах компаний — `daily.yml` с `mode=news`.
- Коммиты — по-русски, кратко.
